# Deep Delver

An original C# / .NET 8, ASCII, turn-based dungeon adventure. Recover the Star of the Deep from the tenth descent and return to the surface.

## Run

```bash
dotnet run --project DeepDelver
```

Choose Warden, Arcanist, or Ranger and optionally enter a seed. Move with arrows or numpad; `.` rests, `g` picks up, `i` manages inventory, `s` searches, `<`/`>` use stairs, `S` saves, `L` loads, and `?` shows controls. Saves and score history live in the user application-data directory, not in the repository.
